The Project

From occurrence data to a hypothesis a geologist can defend.

Built for OreFox AI Limited, SHG brings data validation, multi-scale spatial statistics, interpretable candidate zones and a reproducible report into one web workflow — with orogenic gold as the proof of concept.

◈

Spatial analysis

Nearest-neighbour, k-NN, Ripley-style clustering, characteristic wavelength, kernel density, spatial graphs and clusters.

▲

3D terrain review

Mapbox GL JS terrain with occurrences, extruded hypothesis zones, pattern centres and radial corridors.

✦

Local, bounded AI

DeepSeek-R1 and Qwen2.5-VL run locally via Ollama — interpreting graphs and choosing only among pre-validated candidates.

⇣

Traceable exports

Every run saves its inputs, filters, plots, GeoJSON, map snapshot and a consolidated PDF report.

⌘

Flexible ingestion

CSV, JSON and GeoJSON with field normalisation, coordinate validation and commodity / deposit filters.

⚑

Honest by design

Outputs are labelled as hypotheses for expert follow-up, with a clearly marked non-AI fallback.
